# Support

For help with TSnooze:

- Read the [README.md](README.md) for installation, configuration, and extension usage.
- Check the issue tracker for existing reports or known limitations.
- Open a new issue if you are reporting a bug or requesting a feature.

For security-related concerns, refer to [SECURITY.md](SECURITY.md) and use the private reporting channels listed there.

This repository does not currently offer a separate support chat or community forum.
